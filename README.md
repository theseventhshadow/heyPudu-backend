# heyPudú Backend

Este proyecto es el backend de **heyPudú**, una aplicación construida con
Spring Boot. Se encarga de exponer la lógica y los servicios necesarios para
la aplicación, incluyendo acceso a datos, validaciones y seguridad.

## Tecnologías

- Java 25
- Spring Boot
- Gradle

## Ejecutar el proyecto

En Windows:

```bash
.\gradlew.bat bootRun
```

Para ejecutar las pruebas:

```bash
.\gradlew.bat test
```
